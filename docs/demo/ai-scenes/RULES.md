# RULES — 공모전 규정 정리 (시연 영상 오프닝 기준)

읽은 곳 (2026-11-15 02:30 KST 기준): `/guide`, `/guide/rules`, `/guide/submission`, `/faq`, `/terms`
원칙: 적혀 있지 않거나 애매하면 **확인 필요**로 두고 보수적으로 간다.

## 확인된 사실
- 시연 영상은 **선택 제출물**, "목업 · 프로토타입 · 화면 녹화 인정". 제출하면 단계별 가산점. 영상 길이·형식 규정은 없음.
- 접수: 이메일 appdevchallenge@hyundai-partners.com, 마감 2026.11.15 (FAQ: 23:59). 수정 제출 가능, 마지막 제출본으로 심사.
- 이용약관 제7조 2항: 출품작에 포함된 **이미지·음원·영상·글꼴·상표** 등은 지원자가 적법하게 쓸 권한을 가져야 하고, 제3자 권리침해 분쟁은 지원자 책임.
- 제7조 3항: 지식재산권 침해 우려, 타인 개인정보 노출, 선량한 풍속 위반 자료는 운영자가 삭제 가능.
- 제9조 2항: "출품작의 내용을 사실과 다르게 표시하는 행위" 금지.
- (참고) 숏폼 챌린지는 별개 부문(세로 30초~1분, SNS 게시). 이번 시연 영상과 무관.
- (참고) 제9조 3항: 사이트에 자동화 수단으로 접근·수집 금지. 규정 확인을 위해 공개 안내 5쪽만 읽었고 그 이상은 접근하지 않음.

## 항목별 정리
| 항목 | 규정 | 판단 |
|---|---|---|
| AI 생성물 허용 여부 | 언급 없음 | **확인 필요.** 금지 문구는 없음. 단, 제9조 2항(사실과 다르게 표시 금지) 때문에 연출 장면을 실제 상황·실제 앱 동작으로 오해하게 하면 안 됨 → 오프닝에 **"연출 장면 · AI 생성" 표기 권장(사실상 필수로 취급)**. 오프닝 다음의 앱 화면은 실제 녹화임을 구분. |
| AI 표기 의무 | 언급 없음 | **확인 필요.** 보수적으로 표기한다. 표기 자리(화면 오른쪽 아래)를 비워 둔 구도로 만듦. |
| 현대차 로고·차명 | 언급 없음 (사이트 상단의 HYUNDAI MOTOR GROUP 로고는 주최 측 것) | **확인 필요.** 상표 사용권 근거가 없으므로 **로고·엠블럼·차명·Pleos 로고를 영상에 넣지 않음.** 차 실내는 특정 차종을 알아볼 수 없게. |
| 음악 저작권 | 제7조 2항 — 음원은 적법한 권한 필요 | 녹음 음원·기성곡 사용 안 함. 필요하면 numpy로 합성한 낮은 실내 소음만. |
| 폰트 저작권 | 제7조 2항 — 글꼴 적법 권한 필요 | 오프닝 자체에는 글자를 넣지 않음. 담당자가 자막을 넣는다면 앱에서 쓰는 Asta Sans(오픈 라이선스 여부 담당자 확인) 등 상업 이용 가능한 폰트 사용. |
| 실존 인물 출연 | 언급 없음. 제7조 3-4(타인 개인정보 노출) 해당 가능성 | 실존 인물 없음. AI 인물만, 특정인 얼굴 복제 금지. 초상권 문제 회피. |
| 생성 도구 워터마크 | 언급 없음 | **확인 필요.** 금지 문구는 없으나, 도구 약관(Gemini/Veo의 SynthID·표시 워터마크, Grok 표시)상 지우지 않는 것이 안전. 워터마크가 남으면 위치를 STATUS/REPORT에 적고 **지우지 않음**. 담당자 표기 자리와 겹치지 않게 정리. |
| 운전 안전 묘사 | 언급 없음 (제7조 3-3 선량한 풍속) | 벨트 착용, 휴대폰 없음, 과속·사고·피 장면 없음. |
